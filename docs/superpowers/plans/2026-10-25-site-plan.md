# Game website implementation plan

Goal: approved interactive landing page, static and portable. Tech: HTML/CSS/JS, no runtime packages.

1. Write engine behavior tests: 3 actions/turn, arrow direction only, legal moves, undo full state, reset, victory. Run red.
2. Implement isolated puzzle state engine; verify green.
3. Prepare hardware-border artwork from approved reference, local font and authentic media. Build responsive hero, equal-grid puzzle, 3-key sequence, nonduplicated teaching diagrams, media lightbox and Steam links.
4. Verify engine and DOM interactions, all local references, reduced motion/mobile CSS; inspect browser where available. Review whole implementation and fix findings.
5. Package private Site and GitHub Pages-ready ZIP. Verify deployed status and deliver local version.

Review focus: browser Alt+F4 must not be intercepted; rejected move must not corrupt history; player icon stays upright; all occupied tiles equal neighbors; input3 visible through turn completion; tiny screens and focus controls; source contains no private development files.
